=================================================================
 ESEMPI fetch() per POST /api/repairorder/saveJobcard (djc)
=================================================================

Endpoint: https://dev.wiadvisor-woc.stellantis.com/api/repairorder/saveJobcard

Note generali:
- Ogni chiamata deve sempre includere "roInfo" con i campi M obbligatori
  (sourceApplication, dealerId, updateDateTime) + almeno uno tra
  dmsRepairOrderId / jobCardSrpId / jobCardLegacyId [M(C)].
- "customerId" e "appointmentInternalId" sono obbligatori quando invii
  rispettivamente customerInfo[] e appointments[] [M(O)].
- In customerInfo[], "contactInfo" e "personalInfo" sono campi FRATELLI
  (non annidare contactInfo dentro personalInfo, viene rifiutato dalla API).
- Sostituisci i valori (dmsRepairOrderId, dealerId, customerId, ecc.) con
  quelli reali del Repair Order che stai testando.


-----------------------------------------------------------------
1) SaveRoInfo — car wash, part preferences, obfcm, ecc.
-----------------------------------------------------------------

fetch('https://dev.wiadvisor-woc.stellantis.com/api/repairorder/saveJobcard', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    roInfo: {
      dmsRepairOrderId: "84564621",
      sourceApplication: "WIADVISOR",
      dealerId: "0062230",
      updateDateTime: new Date().toISOString(),
      interiorCarWash: true,
      exteriorCarWash: true,
      partPreferences: [
        { old: true, original: true, returned: false, circularEconomy: false }
      ],
      obfcm: true,
      waitOnSite: false,
      vehicleIdentificationTagNumber: "TAG-999",
      loanerFlag: false
    }
  })
})
.then(response => response.json())
.then(data => console.log(data))
.catch(error => console.error(error));
